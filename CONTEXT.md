# Medical Transcription

A platform where clinicians record or upload consultations, get transcripts and AI-derived clinical records from them, and export shareable reports.

## Language

### Transcription

**Session**:
A user's saved transcription work product: a Transcript plus, optionally, a Document and an Extraction. One of three types: ambient, file-transcription, or dictation.
_Avoid_: recording, "session" for auth state (that's a Login)

**Login**:
A user's authenticated period, carried by a JWT.
_Avoid_: session

**Transcript**:
The raw text produced from a Session's audio.
_Avoid_: transcription (the process, not the text)

### Clinical output

**Extraction**:
The 15-field structured clinical record the AI Assistance module derives from a Transcript (summary, chief complaint, diagnosis, medications, …).
_Avoid_: AI assistance text, summary (one field of it), extraction results

**Document**:
A clinical document generated by Corti from a Transcript via a Corti Template, composed of named sections.
_Avoid_: report

**Report**:
An exportable file (PDF, Word, or Markdown) built from an Extraction via a Report Template. No LLM involved.
_Avoid_: document

**Corti Template**:
A composition of Corti sections that drives Document generation (e.g., GP letter).
_Avoid_: template (unqualified)

**Report Template**:
A named selection of Extraction fields that defines a Report's shape (SOAP, Full Clinical Report, Brief Summary).
_Avoid_: template (unqualified)

### Search

**Embedding**:
A fixed-length numeric vector representing the meaning of a piece of text, used to compare texts by similarity.
_Avoid_: vector (ambiguous)

**Chunk**:
A contiguous span of a Transcript embedded individually, so search can match a specific passage rather than the whole Transcript.

**Semantic Search**:
Retrieval of a user's own Sessions by meaning-similarity between a query and stored Embeddings.
_Avoid_: vector search, AI search
